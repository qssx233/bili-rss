OPML（懒人包）

懒得一条条加的话，这儿还有份 OPML，两个源都打包好了，丢进阅读器一次就能订完，不用来回复制粘贴。Feedly、Inoreader、Follow 和 AgrReader 都认这个格式。

怎么订阅

  1. 上面随便挑一个地址复制，两个都想要就都复制。
  2. 粘进你常用的阅读器，AgrReader、Feedly、Inoreader、Follow 都行。
  3. 剩下的事交给它，更新是自动的，你不用天天回来查。
  4. 用 AgrReader 的注意一下：「打开方式」得设成「内容摘要」，不然点封面进不了播放页（这个坑我踩过）。

每条里有什么

投稿源里每条都带封面大图、完整简介，播放、弹幕、评论、点赞、投币、收藏这几项数据加时长，正文里还嵌了官方播放器，另外十条热门评论。稍再看源轻一点：封面、UP主、分区、看到第几秒的进度和简介，评论区没带——一个待看清单，要那么全干嘛。

两个源都跑在 GitHub Actions 上，每天早上自动跑一次，电脑关着也不影响。
